# Cloud Next MCP release 0.37.0 — interactive charts

This source release advances the Skills Factory Lab catalog and Cloud Next chart response contract together.

- Canonical implementation: Skills Factory main commit `47163a2b354ec98f8b24e24da41d2b0d64f3dea1` (PR #355).
- Bar and line chart tools declare a self-contained MCP Apps HTML view. It renders interactive HTML/CSS/SVG with clickable marks, line-series toggles and accessible tabular values. Exact SVG and caller-supplied data remain available in `structuredContent`; the widget performs no external requests.

The adapter bundle is generated from the canonical repository and ignored in the Site source mirror. This release record gives the provider mirror a tracked source change when an adapter-only release changes the deployment archive, so Site version deduplication cannot silently reuse an older numbered version. The deployed Site commit and embedded canonical revision remain separate and must both be checked in `runtime_info`.

Validation for the implementation passed 24 MCP contract tests, the source-sync test, TypeScript, Site lint/build, Lab artifact validation, isolation validation, generated-catalog parity, plus the Site CI, Domain integrity and Validate skills workflows for the canonical implementation commit. Site CI also passed for this release-record change. The Site workflow regenerates the embedded Lab artifact and its hashes from the exact canonical source commit; the resulting Site version, provider mirror commit and runtime Lab identity must be confirmed from the official deployment result and live `runtime_info`, not inferred from this record.
