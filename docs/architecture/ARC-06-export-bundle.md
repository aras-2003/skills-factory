# ARC-06 architecture export bundle

The export adapter accepts the same validated visualization IR used by ARC-03 and writes a deterministic, static bundle:

- `architecture.svg`: script-free SVG with a title, description, source revision, model digest, and explicit node/relation records. Unknown relations remain visibly labeled `UNKNOWN`.
- `architecture.txt`: complete accessible equivalent with every node, directed relation, state, and source evidence anchor.
- `export-manifest.json`: exact model IDs, counts, digests, and the format embedding matrix.

Call `build_export_bundle(model, output_dir)` from `scripts.architecture.export_bundle`. The destination must be a fresh directory. The adapter validates the model before creating any output and refuses symlinked paths.

## Embedding matrix

| Format | Interactivity | Diagram representation | Accessible equivalent | Generated by this adapter |
| --- | --- | --- | --- | --- |
| HTML | Interactive | Keep the separately produced self-contained HTML and its original model | Include `architecture.txt` | No |
| SVG | Static vector | Complete node/relation listing with provenance | SVG title/description plus `architecture.txt` | Yes |
| PNG | Static raster | Rasterize this bundle's SVG; retain its manifest and text equivalent | Use `architecture.txt` as long description | No |
| DOCX | Flattened media | Embed SVG or its rasterized derivative; no interactive HTML | Image alt text plus `architecture.txt` in the document | No |
| PDF | Flattened media | Embed SVG or its rasterized derivative; no interactive HTML | Tagged figure plus `architecture.txt` as description | No |
| PPTX | Flattened media | Embed SVG or its rasterized derivative; native editable shapes are not provided | Image alt text and `architecture.txt` in notes or appendix | No |

The matrix describes integration requirements; it is not a claim that this repository generates PNG, DOCX, PDF, or PPTX files. In particular, no interactive behavior survives flattening, and native editable PowerPoint shapes are outside this adapter. A consumer must carry the exact manifest and text equivalent alongside its embedded media. Do not silently drop model nodes or relations when converting.

## Verification

`tests/architecture/test_export_bundle.py` uses one fixture for the SVG, text equivalent, and manifest. It verifies exact node/relation ID coverage, counts, unknown-state retention, provenance, safe escaping, accessible SVG elements, format boundaries, and fail-closed output-path behavior. This is an adapter contract test, not an end-to-end test of Office/PDF renderers or a Site runtime test.
