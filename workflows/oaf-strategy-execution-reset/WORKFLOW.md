# OAF Strategy Execution Reset Workflow

## Purpose
Restore traceability from strategic outcomes to capabilities, portfolio choices, ownership, funding and evidence.

## Entry criteria
Use only when the request involves a broken outcome-to-capability/portfolio/funding chain, cross-domain strategy execution accountability, or an enterprise-wide execution reset.
For one bounded implementation architecture question, individual funding ranking with already comparable cases, or a single decision-rights dispute, route directly to the relevant specialist instead. Missing strategy or governance facts are questions, not license to invent an operating model.

## Stages
1. Run `strategy-to-execution-diagnostic`.
2. Identify the small set of strategic outcomes that require repair.
3. Use `capability-gap-analysis` where outcomes depend on insufficient organisational capabilities.
4. Use `portfolio-health-review` to test whether the current portfolio can deliver those outcomes.
5. Use `portfolio-prioritization` only when initiative evidence is comparable enough.
6. Review decision ownership and funding authority with `decision-rights-review`.
7. Close the loop with `evidence-loop-review`.
8. Use `transformation-blueprint` only when the diagnosis and target direction are sufficiently evidenced.

## Output contract
Strategic outcomes; traceability breaks; capability gaps; portfolio implications; ownership/funding issues; evidence-loop gaps; prioritized reset actions.

## Stop conditions
Do not build a new portfolio scoring system when the core problem is missing strategy traceability or ownership.
