# Strategy / Enterprise Architecture / Executive Work

> **Status:** mixed. The `financial-modeling`, `market-economics`, `strategy-economics`, and `value-realization` directories contain candidate source implementations; other entries below remain proposed capability names, not current source or runtime availability.

Skills for structured executive decision support and architecture work.

| Skill | Purpose |
|---|---|
| `strategy-challenge` | Test strategic assumptions, causal logic and missing alternatives. |
| `architecture-review` | Assess architecture decisions, constraints, dependencies and trade-offs. |
| `architecture-decision-record` | Produce a concise ADR with context, options, decision and consequences. |
| `business-case-review` | Challenge benefits, costs, assumptions, risks and sensitivity. |
| `operating-model-review` | Evaluate accountability, global/local split, governance and decision rights. |
| `capability-map-review` | Check capability decomposition, overlaps, gaps and business usefulness. |
| `portfolio-prioritization` | Compare initiatives using explicit strategic and delivery criteria. |
| `governance-design` | Define forums, decision rights, escalation and control mechanisms. |
| `kpi-design` | Design metrics that measure outcomes rather than activity alone. |
| `vendor-evaluation` | Compare vendors using evidence, fit, cost, risk and lock-in. |
| `executive-decision-brief` | Convert complex analysis into a board/executive decision note. |
| `board-message-compression` | Reduce detail to the smallest set of facts needed for executive action. |
