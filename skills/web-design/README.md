# Web / Design / Motion

> **Status:** active candidate design skills. Candidate maturity requires exact-version runtime evaluation before promotion.

The pinned UI/UX Pro Max review is a non-executable reference for future design skills. It does not add a package dependency, copy upstream datasets, enable a production capability, or call a remote MCP. See [the adapter contract](../../docs/web-design/ui-ux-pro-max-adapter.md).

The `interface-design` skill defines screen and flow briefs. `implementation-brief` turns an approved concept into a build-ready handoff, while `visual-regression-review` and `accessibility-gate` keep evidence and test limits explicit. These are candidate skills: source/fixture checks do not establish model routing or runtime behavior; exact-version runtime evaluation is still required before promotion.

Skills for turning strategy and content into high-quality web concepts and implementations.

| Skill | Purpose |
|---|---|
| `interface-design` | Define hierarchy, navigation, responsive behavior, states and accessible interaction for one screen or user flow. |
| `design-critique` | Review a supplied visual artifact with evidence-bound findings and concrete repair proposals. |
| `reference-analysis` | Extract useful mechanics from visual references without copying surface style. |
| `concept-to-metaphor` | Translate business meaning into a clear visual/system metaphor. |
| `motion-storyboard` | Define motion, scroll choreography, state transitions and narrative sequence. |
| `implementation-brief` | Convert an approved concept into a precise build specification. |
| `visual-regression-review` | Compare implementation against approved concept and identify regressions. |
| `seo-content-audit` | Review metadata, content structure and discoverability. |
| `accessibility-gate` | Review accessibility risks not already covered by deterministic tests. |

Rule: deterministic tests such as broken links, responsive checks and accessibility scans belong in CI where possible; AI skills handle judgment-heavy review.
